# Example Integration (Template)

Copy this directory to create a new integration. Edit this README to describe:

1. **What this integration captures** — emails, events, messages, etc.
2. **What external system it depends on** — Gmail API, Notion, Slack, etc.
3. **Setup steps** — credentials, deploy commands, schedule configuration
4. **Files in this directory** — scripts, prompts, OpenAPI specs, etc.
5. **How to test it** — what to watch for in logs, expected captures
