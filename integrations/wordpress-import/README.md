# WordPress Import

> Setup guide for importing WordPress portfolio and blog content into Brain Bank. Requires a WordPress MCP server (or similar) already connected — this doc doesn't set that up, it tells you what to do once you have one.

## What it captures

Published posts and key pages from your WordPress site(s), making that content searchable by meaning across all AI clients.

## Files

- `setup.md` — on-demand import instructions, selective import options, and an automated webhook approach

## Status

Manual on-demand import, with an optional webhook path for ongoing sync.
